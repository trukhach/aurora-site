САЙТ «АВРОРА» — КАК ВЫЛОЖИТЬ

Структура:
  public/            — содержимое кладём в корень сайта на хостинге
    index.html       — страница (можно открыть двойным щелчком для просмотра)
    assets/          — стили и скрипт, без внешних библиотек
    send.php         — защищённый приём заявок, отправляет их в Telegram
    .htaccess        — заголовки безопасности, HTTPS, запрет листинга (Apache)
    robots.txt
  aurora-private/    — кладём РЯДОМ с папкой сайта, не внутрь (недоступна из браузера)
    config.example.php → переименовать в config.php и заполнить
  nginx.conf         — то же, что .htaccess, для nginx

Заявки в Telegram:
  1. В Telegram написать @BotFather → /newbot → получить токен.
  2. Написать своему боту любое сообщение, открыть
     https://api.telegram.org/bot<ТОКЕН>/getUpdates и взять chat.id.
  3. Вписать токен и chat_id в aurora-private/config.php, salt — любая длинная случайная строка.

Защита:
  - CSP: выполняются только наши скрипты, сторонний код на страницу не попадёт
  - HSTS и принудительный HTTPS, запрет встраивания сайта в чужие фреймы
  - форма: одноразовый CSRF-токен, проверка домена, honeypot, тайм-ловушка,
    лимит 3 заявки за 10 минут и 10 в сутки с одного IP, проверка и очистка полей,
    сообщение в Telegram уходит простым текстом
  - токен бота лежит вне публичной папки
  - PHP 7.4+ (лучше 8.x) с расширением curl
