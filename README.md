# Аврора — сайт рекламного агентства

Одностраничный сайт aur0ra.ru: вывески, световые короба, фирменный стиль. Челябинск.

## Структура

- `public/` — готовый сайт, содержимое кладётся в корень хостинга
- `aurora-private/` — настройки формы. Кладётся **рядом** с папкой сайта, не внутрь. `config.example.php` переименовать в `config.php` и заполнить (токен Telegram-бота, chat_id, salt). `config.php` в репозиторий не попадает.
- `nginx.conf` — пример конфигурации для nginx (для Apache уже есть `public/.htaccess`)
- `src/` и `build.py` — исходники. После правок: `python3 build.py`, результат в `dist/`

## Требования

Хостинг с PHP 7.4+ и расширением curl (для формы заявки). Без PHP сайт работает, но форма не отправляет заявки.

## Защита

CSP и заголовки безопасности, HTTPS, одноразовый CSRF-токен, honeypot, тайм-ловушка и лимит заявок по IP в `send.php`. Секреты хранятся вне публичной папки.
